# TITLE:Code Snippet Vault

## Features 

- **May navigation** — sa ano main window makikita mo lahat ng snippets mo, tapos pag nag-add ka o nag-edit, may lalabas na hiwalay na window (popup) para doon mo gawin, tapos babalik ka sa listahan pagkatapos.
- **Live na listahan** — gamit ang JTable na directly kumukuha ng laman mula sa database, kaya updated palagi ang makikita mo.
- **Natatandaan ang preferences mo** — natatandaan ng app yung huling language na pinili mo (sa filter at sa Add form), gamit yung built-in na Preferences API ng Java.
- **SQLite database, may full CRUD** — naka-save ang lahat ng snippets sa ano local SQLite database (JDBC), kaya kaya mo i-save, tingnan, i-edit, at i-delete.
- **May search** — makakahanap ka ng snippet by title, live habang nagta-type ka.
- **May API integration** — meron "Get Coding Tip" button na kumukuha ng random programming joke galing sa isang public API.

## Ginamit

- Java (Swing / AWT), ginawa gamit ang GUI Builder ng NetBeans
- SQLite, gamit ang sqlite-jdbc driver
